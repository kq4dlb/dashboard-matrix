## 0.1.0-beta.1 — 2026-07-24

- Automated version roll: Version display, update indicator, and automated release workflows.


## Unreleased

- Standardized automatic startup after reboot across Linux, Raspberry Pi, Windows, and Docker.
- Added Linux and Windows autostart management scripts for status, enable, disable, restart, and logs.
- Added optional Raspberry Pi desktop kiosk startup and release packaging for startup-management assets.

- Reorganized Administration into accessible tabs for Overview, Dashboards & Cards, Layouts & Sharing, Sources & Catalog, and Extensions.

## 0.1.0-beta

- Established Dashboard Matrix as an independent dashboard product.
- Added a first-run wizard and Blank, Amateur Radio, and Home Lab templates.
- Added layout import analysis and conflict strategies.
- Added Admin layout export, screenshot preview, and GitHub publishing.
- Added a complete Dashboard Matrix Exchange repository template.
- Added stable, beta, and nightly release-channel checks.

- Added explicit plugin permissions and environment-variable secret mappings.
